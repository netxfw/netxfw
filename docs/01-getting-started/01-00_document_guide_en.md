# NetXFW Documentation Guide

Welcome to NetXFW! This documentation will help you quickly understand how to use this firewall system.

This documentation is organized by **functional modules** and **user roles**. You can select the corresponding sections based on your needs:

### 1️⃣ Getting Started (Required Reading)
- **Project Introduction** - Understand what NetXFW is and what it can do
- **Documentation Index** - Complete documentation map

### 2️⃣ Installation and Deployment
- **Security Best Practices** - Security configuration suggestions before installation
- **Configuration Initialization** - Quick system configuration initialization

### 3️⃣ Quick Start (Common Commands)
- **CLI Command Manual** - Detailed description of all command-line tools
- **Rule Import/Export** - Batch management of firewall rules

### 4️⃣ Configuration Management
- **BPF Map Capacity** - Adjust system capacity configuration
- **Performance Tuning** - Optimize firewall performance

### 5️⃣ Advanced Features
- **Cloud Environment Support** - Get real client IP (Proxy Protocol)
- **Interface-Specific Mode** - Configuration for specific network interfaces
- **Log Engine** - Log-based automatic protection

### 6️⃣ Plugin Development
- **Plugin Development Guide** - Develop Go language plugins
- **XDP Development Guide** - Develop BPF/XDP plugins

### 7️⃣ Performance Tuning
- **Performance Benchmarking** - Understand system performance

### 8️⃣ Troubleshooting
- **Common Issues** - Problem diagnosis and solutions

### 9️⃣ API Reference
- **REST API Documentation** - Web API interface description
- **Configuration Management API** - Unified configuration management
- **Monitoring Metrics API** - Get system monitoring data

### 🔟 Appendix
- **Architecture Design** - System architecture description
- **Packet Filter Flow** - Technical details
- **Testing and Evaluation** - Testing methods and evaluation reports
